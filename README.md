# System Analysis and Design: Chapter 1 Activity

A presentation and video script summarizing the Chapter 1 activity on **System Analysis and Design (SAD)**, based on the chapter *"Architecting the Digital Future"*.

## What this project covers

**Part 1: Conceptual Understanding**
1. Definition of SAD
2. The three components of SAD: System Analysis, System Design, and Implementation
3. Why SAD matters in software development, with real examples (Amazon, Uber)

**Part 2: System Analyst Role**

4. The role of a system analyst: turning business ambiguity into technical clarity
5. Four key responsibilities: requirement gathering, feasibility analysis, system design, and validation and maintenance (with requirement gathering explained in detail)

**Part 3: SDLC vs Agile**

6. What the Software Development Life Cycle is, and its models: Waterfall, Iterative, Spiral, V-Model, and Agile
7. Comparison of SDLC and Agile by flexibility and development approach
8. A real-life scenario where Agile is more suitable: a food-delivery startup

## How to use

1. Download `SAD_Chapter1_Activity.pptx` and open it in PowerPoint.
2. To see the speaker notes, go to **View → Notes**, or use **Slide Show → Presenter View**.
3. Read from one of the script files while recording the video presentation.

## Learning objectives

- Explain the fundamentals of System Analysis and Design
- Describe the role of system analysts
- Differentiate between SDLC and Agile
- Identify different types of system models
- Apply concepts to real-world systems
